# Resource Coordinator Archive

This directory preserves the former Scripts-owned Resource Coordinator documentation, plans, handoffs, and historical H4 evidence. The original tracked files were relocated without content edits as part of the isolated source-retirement candidate.

The canonical implementation and H4 qualification tooling are maintained in `llm-agent-toolkit/modules/resource_coordinator`. The archived H4 plans describe historical Scripts revisions; current bundle generation must use an explicit immutable Toolkit commit and the pinned historical Scripts baseline.

The local Phase-D owner worktree contains separate uncommitted documentation changes. Byte-for-byte copies of the outstanding owner material are preserved in [`phase-d-owner-followup-20261023/`](phase-d-owner-followup-20261023/), with provenance and implementation-status distinctions. The protected source worktree remains unchanged. This archive does not authorize integration of the unmerged owner implementation or proposed behavior.
