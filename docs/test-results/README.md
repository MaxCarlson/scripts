# Repository Validation Results

This directory stores tracked validation reports generated by the repository-root `Invoke-Tests.ps1` dispatcher.

Reports are grouped by validation target:

```text
docs/test-results/<target>/YYYYMMDD-HHMMSS_<target>.txt
```

The current target selection and commands are defined in:

```text
validation-targets.json
```

## Normal Workflow

From the repository root:

```powershell
./Invoke-Tests.ps1
```

The script:

1. reads the validation target manifest,
2. selects the configured default target or targets,
3. resolves the repository Python environment,
4. installs each target's declared development dependencies unless `-SkipBootstrap` is used,
5. runs its language-native test commands,
6. runs its platform-specific validation scripts,
7. records complete stdout, stderr, environment context, exact commands, exit codes, and summaries,
8. writes one dated report per target under this directory.

Stage and push the newly generated report files so a remote implementation agent can inspect them without manual copy/paste.

## Target Selection

List configured targets:

```powershell
./Invoke-Tests.ps1 -ListTargets
```

Run selected targets:

```powershell
./Invoke-Tests.ps1 -Target rrbackup
```

Run all configured targets:

```powershell
./Invoke-Tests.ps1 -Target all
```

## Safety

Production access is disabled by default. Targets may expose explicit read-only checks through:

```powershell
./Invoke-Tests.ps1 -IncludeProductionReadOnly
```

The manifest must never enable destructive production operations as part of the default validation path.
