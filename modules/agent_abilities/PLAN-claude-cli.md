# Agent Abilities v0.3.0 - Expansion Plan

> Generated by Claude CLI (Opus 4.6) - 2026-02-15

## Context

The `agent_abilities` module (v0.2.0) currently manages 4 resource types (agents, prompts, instructions, skills) across 3 CLI targets (claude, codex, cursor). After discovering the **awesome-copilot** repo (`~/projects/awesome-copilot/`), which catalogs 6 resource categories with thousands of community examples, we're expanding the module to:

1. Add **hooks** and **collections** as new resource types (6 total)
2. Add **GitHub Copilot** as a sync target (`.github/copilot/`)
3. Copy the **TEMPLATE/spec docs** from awesome-copilot into the module's `docs/` for each type
4. Support scanning/importing from the awesome-copilot repo on demand

## Step 2: Update Manager for Non-Markdown Formats

**File: `agent_abilities/manager.py`**

### 2a. Parse hooks (JSON, not markdown frontmatter)

Add `parse_hooks_json()`:
```python
def parse_hooks_json(file_path: Path) -> Optional[Dict[str, Any]]:
    """Parse a hooks.json file."""
    content = json.loads(file_path.read_text(encoding="utf-8"))
    events = list(content.get("hooks", {}).keys())
    return {
        "version": content.get("version", 1),
        "events": events,
        "description": f"Hook with events: {', '.join(events)}",
    }
```

### 2b. Parse collections (YAML, not markdown)

Add `parse_collection_yaml()`:
```python
def parse_collection_yaml(file_path: Path) -> Optional[Dict[str, Any]]:
    """Parse a .collection.yml file."""
    import yaml
    data = yaml.safe_load(file_path.read_text(encoding="utf-8"))
    return {
        "id": data.get("id"),
        "name": data.get("name"),
        "description": data.get("description"),
        "tags": data.get("tags", []),
        "items": data.get("items", []),
    }
```

### 2c. Update `parse_resource()` dispatch

In `parse_resource()`, before the generic frontmatter path, add format-specific branches:

if resource_type == "hook":
