# Plans

Create one directory per substantial plan. Recommended structure:

```text
YYYYMMDD-HHMM_descriptive-plan-name/
├── 00_implementation-plan.md
├── HANDOFF.md
└── ledger/
```

The active Markdown plan contains the structured development-ledger state block. The `ledger/` directory is generated by validation tooling and must not be edited manually.

Small, isolated changes may use a lighter plan when repository instructions permit, but substantial or multi-session work should retain stable item IDs, acceptance criteria, test mappings, and manual checks.
