# Repository Documentation

This `docs/` directory is the planning and handoff root for repository-wide work.

- `agent/DEVELOPMENT_LEDGER_WORKFLOW.md` defines the shared hybrid/local workflow.
- `HANDOFF.md` records the current repository-wide stopping point and next actor.
- `plans/` contains repository-wide implementation plans.
- Each active plan may contain a generated `ledger/` directory with immutable run history and LLM-oriented projections.

Subdirectories with their own adjacent `docs/` and scoped instruction files manage their plans and evidence independently unless a repository-wide plan explicitly coordinates them.
