#### C. Proven Window Suppression Engine (`procwatch/guard/window_guard.py`)

Retains the exact sub-millisecond suppression pipeline from your working `minimize_popups.py` script, wrapped in configurable targeting rules:

1. **Event Loop:** Dedicated thread running `MsgWaitForMultipleObjects(0, None, False, 50, QS_ALLINPUT)` + `PeekMessageW` loop with `SetWinEventHook(EVENT_SYSTEM_FOREGROUND, EVENT_OBJECT_SHOW, ..., WINEVENT_OUTOFCONTEXT | WINEVENT_SKIPOWNPROCESS)`.
2. **Baseline Allowlist:** Snapshots all existing HWNDs via `EnumWindows` on startup so open terminals are never touched.
3. **Neutralization Sequence (`_neutralize_window`):**
* `LockSetForegroundWindow(LSFW_LOCK)`
* Apply `WS_EX_NOACTIVATE` via `SetWindowLongW(hwnd, GWL_EXSTYLE, orig_ex | WS_EX_NOACTIVATE)`
* Relocate off-screen via `SetWindowPos(hwnd, None, -32000, -32000, 0, 0, SWP_NOSIZE | SWP_NOZORDER | SWP_NOACTIVATE)`
* Minimize without activation via `ShowWindowAsync(hwnd, SW_SHOWMINNOACTIVE)`
* Re-enforce during the 0.6s initialization window and restore `orig_ex` on `EVENT_OBJECT_SHOW` so clicking the minimized taskbar icon later restores the window normally
* Restore foreground focus to `last_valid_fg` via `AttachThreadInput` + `SetForegroundWindow` (skipping if `GetAsyncKeyState(VK_LBUTTON) < 0`).


4. **Targeting Modes:**
* `smart` (default): Suppresses new `CASCADIA_HOSTING_WINDOW_CLASS` and `ConsoleWindowClass` windows whose initial title or correlated process indicates non-interactive automation (`\.venv\\Scripts\\python\.exe`, `pythonw?\.exe`, `pwsh\.exe.*-Command`, `cmd\.exe\s+/c`, or background agent/service ancestry), while allowing interactive terminals launched directly from `explorer.exe`.
* `all-consoles`: Suppresses all non-baseline `CASCADIA_HOSTING_WINDOW_CLASS` and `ConsoleWindowClass` windows (identical to your standalone script).
* `observe`: Records window lifecycle and foreground-theft telemetry without modifying window state.

#### D. Complete 10-Command CLI Contract

All options enforce single-dash short flags and double-dash hyphenated long flags (`-x, --long-name`):

1. **`procwatch watch`** — Live forensic stream with optional active popup suppression.
* `-p, --popups-only`: Show only events that produced a visible window or matched popup heuristics.
* `-g, --guard-windows`: Enable active `NeutralizeEngine` window suppression while watching.
* `-m, --guard-mode <smart|all-consoles|observe>`: Guard targeting policy (default: `smart`).
* `-c, --collapse-bursts`: Group repetitive polling spawns into rolling counters.
* `-s, --show-headless`: Include `conhost.exe 0x4` suppressed spawns.
* `-f, --filter-regex <pattern>`: Filter by command line, worktree path, or ancestor name.
* `-o, --output-file <path>`: Stream redacted JSONL events to disk.


2. **`procwatch guard`** — Standalone low-overhead window guard daemon.
* `-m, --mode <smart|all-consoles|observe>`: Suppression policy (default: `smart`).
* `-n, --no-focus-restore`: Minimize without forcing foreground focus back.
* `-t, --title-pattern <regex>`: Custom regex of window titles to suppress.
* `-e, --exclude-pattern <regex>`: Regex of window titles or process names to never suppress.
* `-q, --quiet`: Suppress stdout logging (for `pythonw.exe` background runs).


3. **`procwatch history`** — Query, replay, or export recorded SQLite history.
* `-t, --time-window <duration>`: Lookback window (e.g., `15m`, `2h`, `7d`).
* `-p, --popups-only`: Return only incidents with confirmed or suppressed popup windows.
* `-a, --agent-filter <name>`: Filter by initiator tag (`codex`, `claude`, `task`, `docker`).
* `-r, --replay-timeline`: Render events chronologically with inter-event millisecond deltas.
* `-e, --export-bundle <path>`: Export a redacted JSON evidence bundle for an AI agent.


4. **`procwatch explain`** — Causal breakdown of a recorded incident or live PID.
* `-i, --incident-id <id>`: Explain a stored incident (ancestry, typed `evidence_edges`, confidence, alternative candidates, and remediation).
* `-p, --pid <int>`: Inspect a currently running PID (PEB `CWD`, Git worktree, parent chain, open HWNDs).
* `-j, --json-output`: Emit structured JSON.


5. **`procwatch mark`** — Drop an instant user bookmark when a sub-second window flashes.
* `-l, --label <text>`: Note describing what you were doing when the flash occurred.
* `-w, --window-seconds <float>`: Correlation radius around the mark (default: `3.0`).


6. **`procwatch analyze`** — Detect periodicity loops and compare before/after remediation baselines.
* `-p, --periodicity`: Cluster recurring spawns and compute inter-arrival intervals.
* `-b, --baseline-window <duration>`: Compare recent popup rates against an earlier baseline period.
* `-w, --window-seconds <int>`: Analysis lookback window in seconds (default: `3600`).
* `-j, --json-output`: Emit structured JSON.


7. **`procwatch scan`** — Static AST/parser scanner for unguarded subprocess calls in Python & PowerShell.
* `-d, --directory <path>`: Target directory or repository (default: `.`).
* `-w, --include-worktrees`: Discover and scan all active worktrees via `git worktree list --porcelain`.
* `-u, --unified-diff`: Print reviewable unified diffs adding `CREATE_NO_WINDOW` on `win32` (default output mode).
* `-a, --apply-fixes`: Apply vetted `libcst` fixes in place (refuses dirty files unless `-f, --force` is passed).
* `-j, --json-output`: Emit structured findings for agent remediation.


8. **`procwatch audit`** — Read-only audit and opt-in remediation for Scheduled Tasks, Startup entries, and Windows Terminal delegation.
* `-t, --target-type <all|tasks|startup|defterm>`: Scope of audit (default: `all`).
* `-n, --task-name <name>`: Filter to a specific Scheduled Task path/name.
* `-a, --apply-task-fix`: Wrap a culprit Scheduled Task in `procwatch exec` or `pythonw.exe` after saving an XML backup to `~/.procwatch/backups/`.


9. **`procwatch exec`** — Supervised headless command runner with captured output and exit codes.
* `-c, --command <cmd...>`: Command and arguments to execute with `CREATE_NO_WINDOW`.
* `-w, --working-dir <path>`: Working directory for the child process.
* `-t, --timeout-seconds <int>`: Terminate child process tree if timeout is exceeded.
* `-k, --keep-console-on-error`: Emit desktop/console alert only on non-zero exit code.


10. **`procwatch doctor`** — Read-only diagnostic check of collectors, Sysmon status, privileges, and storage health.
* `-v, --verbose`: Show detailed capability matrix (Windows build, `Console\%%Startup` delegation GUIDs, Event Log permissions, DB size, and drop counters).
* `-j, --json-output`: Emit machine-readable health report.
