When acting as the coordinator for authorized repository work, proactively use
the local-agent-handoff skill with opencode_worker for worthwhile bounded subtasks.
An instruction disabling delegation takes precedence. Give the worker the absolute
workspace, objective, relevant context, allowed changes and completion checks.
Review the result and verify its evidence before integration. Keep tiny tasks
local when handoff and review would cost more than doing them directly. If the
worker is unavailable or blocked, continue locally or report the specific gap.
When acting as the delegated worker, complete the assigned task directly.
