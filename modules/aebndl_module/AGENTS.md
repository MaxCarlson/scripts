# AGENTS.md

## Project Setup
- **Development Environment:**
  - Create the `mamba` environment: `mamba create -n dlpn python=3.10`
  - Activate the environment: `mamba activate dlpn`
- **Install Dependencies:**
  - For `aebn-vod-downloader`: Navigate to the repository root and run `pip install -e .`
  - For `procparsers`: Navigate to the `procparsers` subdirectory (`cd procparsers`) and run `pip install -e .`
- **Environment Variables/Config:** No specific environment variables or config files are explicitly required beyond the `mamba` environment activation.

## How to Run
- **Run `aebn-vod-downloader` CLI:**
  - Normal mode (with `tqdm` progress bars): `aebndl <URL>` (e.g., `aebndl https://straight.aebn.com/straight/movies/314823/heavenly-pleasures-12#scene-1286105`)
  - JSON output mode: `aebndl --json <URL>` (e.g., `aebndl --json https://straight.aebn.com/straight/movies/314823/heavenly-pleasures-12#scene-1286105`)
- **Run `procparsers` Integration Test:**
  - From the repository root: `python test/dlscript.py -f test/files/downloads/ae-stars/matty_parez.txt --quiet`
- **Run `aebn-vod-downloader` Unit Tests:**
  - From the repository root: `python -m unittest tests/base_test.py`
- **Linting/Formatting:** No specific linting or formatting commands have been explicitly used or configured in this session.

## Code Style & Conventions
- **Python Version:** Python 3.10 (as used in the `dlpn` mamba environment).
- **Formatting/Linting:** No explicit formatting or linting tools have been enforced or run in this session.
- **Naming Conventions:** Existing codebase uses `snake_case` for variables and functions, and `_leading_underscore` for "private" members.

## Git & PR Workflow
- **NEVER MAKE A COMMIT WITHOUT ASKING FIRST**
  - Even if you have permission to make all changes without asking. Always ask before committing
- **No Initiating Commits** Never initiate making a commit. Commits should only be made upon direct request.
- **Commit Messages:** Follow a conventional commit style (e.g., `feat: Add new feature`, `fix: Resolve bug`).
- **Branching:** Feature branches are used (e.g., `feature/tqdm-byte-metrics`).
- **Updating from Upstream:**
  - Add upstream remote (if not already done): `git remote add upstream https://github.com/estellaarrieta/aebn-vod-downloader.git`
  - Fetch latest changes: `git fetch upstream`
  - Merge/Rebase into your `main` branch:
    ```bash
    git checkout main
    git pull upstream main # or git pull --rebase upstream main
    git push origin main
    ```
  - Rebase feature branch onto updated `main`:
    ```bash
    git checkout your-feature-branch
    git rebase main
    git push origin your-feature-branch --force # Use --force after rebase
    ```
- **Pre-commit/PR Checks:** Ensure all relevant tests pass before committing or creating pull requests. No other specific CI or pre-commit steps have been configured.
